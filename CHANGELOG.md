# Changelog - Artifact Visibility by Expand

- 1.1.1: two bugs found by the in-game test suite (`run.ps1 -Suite av`, 2026-11-26, profile `Claude Test`).
  Dropped artefacts no longer blink: the binder's 2 s refresh timer now runs only for artefacts on the ground, so the
  first update after a drop refreshes before the engine's hide check (before: hidden 10-40 ms after every drop, shown
  again up to 2 s later with the detector show effect and sound). Installer files regenerated: 268 sections (was
  223). `tools/gen_sections.py` now merges only what the engine merges into system_ini (`system.ltx` include tree +
  `mod_system_*.ltx`; base GAMMA's treasure-tier file `grok_items_tier.ltx` had replaced 28 Perk-Based junk
  artefacts) and reads the unpacked vanilla configs for sections that only exist in the `.db` archives (SoC
  artefacts, `monolith_shard`, multiplayer artefacts, DOGMA glowsticks inheriting `af_signet`). Before, 46 sections
  (42 in base GAMMA) kept their glow light / idle particles / detector tier. Reinstall over 1.1.0 with the same options.
  Tested: suite run `20261126-224954` on the 1.1.1 zip (profile `Claude Test`): 7 of 7 scenarios PASS, 0 Lua errors.

- 1.1.0: no more runtime edits of the game config (`system_ini()` writes removed, along with the `[socart_backup]`
  section file). Glow light, idle particles and "detectors find all artefacts" (`af_rank = 0`) are now FOMOD
  installer options: static DLTX files `mod_system_zzzzzzzzzzzzzzzzzz_socart_*.ltx` (named to load after GAMMA's
  `mod_system_zzzzzzzzzzzzzzzzz_grok_artifacts.ltx`), each with 223 artefact sections generated by
  `tools/gen_sections.py` from base GAMMA and the author's mod list. Detector tiers are kept by the binder script
  (default, unchanged). It now skips artefacts with rank 0. MCM: only "Enable mod" (now applies live) and "Debug log";
  the old lights/particles/tiers options are gone (old saved values are ignored). Reinstall over 1.0.x and pick
  the options.
- 1.0.2: removed the MCM option "Artefacts always visible": the mod's whole point is that artefacts are visible, so
  they always are while "Enable mod" is on. Old saved values of that option are ignored.
- 1.0.1: MCM option "Detectors keep their tiers" is now on by default (script defaults table and MCM default). Players
  who saved MCM values keep their choice.
- 1.0.0: first public release. Version label only, no code changes.
- 0.3.0: renamed from "SoC-Style Artefacts Remake" to "Artifact Visibility" (mod name, MCM menu, readmes, zip
  name). No functional changes; MCM id `socart`, file names and the `[SoCArts]` log tag are unchanged, so settings
  and saves carry over. Disable the old-named 0.2.0 install in MO2 when installing this one.
- 0.2.0: new MCM option "Detectors keep their tiers" (off by default). Artefacts stay visible, but `af_rank`
  keeps its original value, so each detector only finds the artefacts of its tier, as in normal GAMMA. The
  artefact binder re-sends "visible" every 2 s to artefacts lying in the world so the engine never hides them
  (resets the engine's 5 s timer only, no effect or sound). Artefacts with another script binder fall back to
  rank 0.
- 0.1.0: first version. Remake of "SoC-style Artefacts (DLTX)" by MaxSpringer as one mod. Artefacts on the
  ground are always visible without a detector; glow light and idle particles have MCM switches (plus master
  switch and debug log). Instead of a fixed DLTX list, the script finds every artefact section when the game loads
  and edits `af_rank` / `lights_enabled` / `particles` in the loaded config, so all GAMMA, junk, storyline and
  other mods' artefacts are covered and GAMMA's later `mod_system_zzz..._grok_artifacts.ltx` can no longer undo it.
  Settings apply on the next save load; nothing runs during gameplay.
